# Music Player App

Простое настольное приложение для воспроизведения музыки, созданное на C# (Windows Forms) в Microsoft Visual Studio. Приложение позволяет выбирать несколько аудиофайлов, формировать плейлист и воспроизводить их с визуализацией звуковой волны.

## Описание

Music Player App - это приложение для воспроизведения аудиофайлов формата MP3, WAV, WMA, M4A, AAC. Пользователь может выбрать один или несколько файлов, добавить их в плейлист и управлять воспроизведением через встроенные элементы управления.

Приложение отображает звуковую волну выбранного трека и показывает прогресс воспроизведения. При завершении текущего трека автоматически включается следующий.

Проект разработан в учебных целях и демонстрирует работу с:
- Windows Forms
- COM-компонентом Windows Media Player
- Кастомной отрисовкой графики (GDI+)
- Диалогами выбора файлов
- Таймерами и обработкой событий

## Требования

Перед началом работы убедитесь, что установлено:

- Microsoft Visual Studio 2019 или выше
- Компонент **".NET desktop development"** в Visual Studio
- .NET Framework 4.7.2 или выше
- Windows Media Player (входит в состав Windows, но может быть отключён)

Если Windows Media Player отключён:

1. Откройте "Панель управления" → "Программы и компоненты" → "Включение или отключение компонентов Windows"
2. Разверните "Компоненты мультимедиа"
3. Поставьте галочку на "Windows Media Player"
4. Нажмите ОК и перезагрузите компьютер

## Установка и запуск

### Шаг 1. Создание проекта

1. Откройте Visual Studio
2. **Файл** → **Создать** → **Проект**
3. Выберите **Windows Forms App (.NET Framework)** - C#
4. Имя проекта: `MusicPlayerApp`
5. Framework: .NET Framework 4.7.2 или выше
6. Нажмите **Создать**

### Шаг 2. Добавление ссылки на Windows Media Player

1. В обозревателе решений правой кнопкой по проекту → **Добавить** → **Ссылка...**
2. Вкладка **COM** → найдите **Windows Media Player** → поставьте галочку → **ОК**
3. Ещё раз: **Добавить** → **Ссылка...** → вкладка **Обзор** → перейдите в:
   ```
   C:\Windows\System32\wmp.dll
   ```
   или
   ```
   C:\Windows\SysWOW64\wmp.dll
   ```
   выберите файл → **ОК**

После этого в разделе **Ссылки** (References) проекта появятся:

```
WMPLib
```

### Шаг 3. Установка платформы x86

1. В меню: **Проект** → **Свойства MusicPlayerApp**
2. Вкладка **Сборка** (Build)
3. **"Платформа целевого объекта"** (Platform target) = **x86**
4. Сохраните

Дополнительно:
5. В главном окне Visual Studio смените выпадающий список с `Any CPU` на `x86`
6. Если платформы x86 нет — **Сборка** → **Диспетчер конфигураций** → в поле "Платформа" выберите `<Создать...>` → введите `x86` → ОК

### Шаг 4. Добавление файлов

1. Скопируйте `Form1.cs`, `Form1.Designer.cs` (содержимое из этого репозитория)
2. Добавьте в проект новый файл `WaveformPanel.cs` (правой кнопкой по проекту → **Добавить** → **Класс**)

### Шаг 5. Сборка

1. **Сборка** → **Очистить решение**
2. **Сборка** → **Пересобрать решение**
3. Нажмите **F5** для запуска

## Описание модулей

### Program.cs

Точка входа в приложение. Настраивает визуальные стили и запускает форму `Form1`.

```csharp
[STAThread]
static void Main()
{
    Application.EnableVisualStyles();
    Application.SetCompatibleTextRenderingDefault(false);
    Application.Run(new Form1());
}
```

### Form1.cs

Основная логика приложения:
- Создание невизуального `WMPLib.WindowsMediaPlayer`
- Обработка кнопок управления (Play, Pause, Next, Prev)
- Работа с плейлистом (добавление, выбор, воспроизведение)
- Обновление прогресса и времени по таймеру
- Регулировка громкости
- Автоматический переход между треками

### Form1.Designer.cs

Содержит описание всех визуальных контролов и метод `InitializeComponent()`. Генерируется Visual Studio автоматически.

### WaveformPanel.cs

Кастомный контрол, наследуемый от `Panel`. Переопределяет метод `OnPaint` и рисует звуковую волну с помощью GDI+.

Основные свойства:
- `IsPlaying` (bool) - играет ли сейчас музыка
- `Progress` (float) - прогресс воспроизведения от 0.0 до 1.0

## Визуализация звуковой волны

Класс `WaveformPanel` рисует звуковую волну на панели в режиме реального времени.

### Принцип работы

1. При изменении размера панели генерируется массив `_wavePoints` - набор точек, описывающих волну.
2. Каждая точка рассчитывается как сумма нескольких синусоид с разной частотой и случайной составляющей.
3. В методе `OnPaint` эти точки соединяются линиями.
4. Линии делятся на две части:
   - **Активная** (яркая, зелёная) - от начала до текущего прогресса
   - **Неактивная** (тёмная, приглушённая) - от текущего прогресса до конца
5. Волна отрисовывается симметрично относительно центральной горизонтальной линии.

### Основные методы

```csharp
private void RebuildWave()   // Генерация массива точек
protected override void OnPaint(PaintEventArgs e)   // Отрисовка
```

### Свойства

```csharp
public bool IsPlaying { get; set; }   // Отображать ли анимацию
public float Progress { get; set; }   // Прогресс от 0.0 до 1.0
```

## Возможные ошибки и их решение

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Не удалось найти тип "AxWMPLib" | Используется визуальный контрол вместо невизуального | Использовать `WMPLib.WindowsMediaPlayer` (без `Ax`) |
| Элементы управления не включены в активном конструкторе | Дизайнер не поддерживает COM-компонент | Добавить плеер в код вручную |
| Не удалось найти тип "WMPLib.WindowsMediaPlayer" | Нет ссылки на WMPLib | Добавить через COM-ссылки: Windows Media Player |
| Ошибка "Platform target" | Проект собирается под Any CPU | Сменить платформу на x86 |
| Файл не найден при воспроизведении | Используется относительный путь | Хранить полные пути в `_filePaths` |
| Автоматический переход не работает | Таймер не запущен | Убедиться, что `timerProgress.Start()` вызван в `PlaySelected` |

### Предупреждения, которые можно игнорировать

При добавлении ссылки на Windows Media Player могут появляться предупреждения:

```
Программа импорта библиотек типов обнаружила метод считывания свойства 
"sessionPlaylistCount" типа "WMPLib.IWMPNowPlayingHelperDispatch" 
с недействительным типом возвращаемого значения.
```

```
По меньшей мере один из аргументов "IWMPGraphEventHandler.NotifyAcquireCredentials" 
не может быть упакован упаковщиком среды выполнения.
```

Это особенности COM-библиотеки `wmp.dll`, они не влияют на работу приложения.

## Примечания

- Приложение требует наличия Windows Media Player в системе.
- Для корректной работы ссылок на COM-компонент рекомендуется собирать проект под платформу **x86**.
- Названия треков в плейлисте отображаются без пути. Полные пути хранятся в отдельном списке `_filePaths`, синхронизированном с `lstPlaylist.Items`.
- При первом запуске форма показывает статус "Пауза" и время "00:00".
